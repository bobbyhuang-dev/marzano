# Alert sounds

Both files come from Google's Material Design product sound resources
(`material_product_sounds.zip`, published at
https://material.io/design/sound/sound-resources.html and mirrored at
https://archive.org/details/material-design-sound-resources), which Google
made available under the Creative Commons Attribution 4.0 licence
(https://creativecommons.org/licenses/by/4.0/). They are unchanged apart from
the file names.

| File                 | Original                                       | Played when       |
| -------------------- | ---------------------------------------------- | ----------------- |
| `focus-complete.mp3` | `01 Hero Sounds/hero_simple-celebration-01`    | a focus round ends |
| `break-complete.mp3` | `02 Alerts and Notifications/alert_high-intensity` | a break ends  |
